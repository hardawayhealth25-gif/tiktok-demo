TIKTOK INTEGRATION
================================================================================

OAUTH ENDPOINTS:
  • Authorize: https://www.tiktok.com/v2/auth/authorize/
  • Token: https://open.tiktokapis.com/v2/oauth/token/

API ENDPOINTS USED:
  • User Info: GET /v2/user/info/
  • Video Init (Draft): POST /v2/post/publish/inbox/video/init/
  • Video Init (Direct): POST /v2/post/publish/video/init/
  • Chunk Upload: POST /v2/post/publish/video/chunk/upload/
  • Publish: POST /v2/post/publish/video/publish/

REQUIRED SCOPES:
  • user.info.basic (read profile)
  • video.publish (publish videos)
  • video.upload (upload files)

ENVIRONMENTS:
  • Sandbox: For testing with sandbox credentials
  • Production: For real deployment with production credentials

GETTING TIKTOK CREDENTIALS
================================================================================

STEP 1: Create Developer Account
  • Go to https://developer.tiktok.com/
  • Sign in or create account
  • Complete verification

STEP 2: Create Application
  • Click "Create App"
  • Fill in details
  • Accept terms

STEP 3: Get Credentials
  • Copy Client Key (App Key)
  • Copy Client Secret
  • Note: Different for sandbox vs production

STEP 4: Configure Redirect URI
  • Set to: http://localhost:5000/auth/tiktok/callback
  • (Change for production)

STEP 5: Update .env
  • Copy .env.example to .env
  • Paste Client Key
  • Paste Client Secret
  • Save and restart app

See README.md "Getting TikTok Developer Credentials" section.

TROUBLESHOOTING QUICK REFERENCE
================================================================================

ModuleNotFoundError:
  → pip install -r requirements.txt

Address already in use (port 5000):
  → lsof -i :5000 && kill -9 <PID>

Invalid Client Key:
  → Verify TIKTOK_CLIENT_KEY in .env matches TikTok Console

Redirect URI Mismatch:
  → Check TIKTOK_REDIRECT_URI matches TikTok Console exactly
  → No trailing slashes!

Video upload fails:
  → Check format (MP4, MOV, AVI, MKV)
  → Check file size (< 100MB)
  → Check access token validity

App won't run:
  → Python 3.9+ installed? Check: python --version
  → Virtual env activated? Check: which python
  → Dependencies installed? Check: pip list

Session not persisting:
  → FLASK_SECRET_KEY set? Check .env
  → Cookies enabled? Check browser settings

See README.md Troubleshooting for more.
